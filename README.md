\# Kinetic Evidence Documentary Engine



Evidence-driven English documentary video generator with an Arabic UI.

Runs \*\*100% offline\*\* — no paid APIs, no mandatory API keys.



\## Features

\- English documentary script → multi-scene evidence-driven video

\- Word-level timestamps (WhisperX → heuristic fallback)

\- English TTS (Kokoro → Piper → espeak-ng → silence fallback)

\- Kinetic typography + Motion Graphics (counters, transitions)

\- Evidence generators: charts, documents, cards, maps, diagrams

\- FFmpeg render with NVENC/CPU fallback

\- Hybrid Media Search: Pixabay, Wikimedia, Archive, NASA, Press Kits

\- AI Image generation (opt-in, watermarked)

\- Arabic Gradio UI, English video content
